# Mouse_Mag

A small Windows utility assigning standard mouse side buttons to Windows Magnifier.

## Button assignments

| Physical button | Windows event | Action |
|---|---|---|
| Front/cable-side button | `XButton2` | Open Magnifier |
| Rear-side button | `XButton1` | Close Magnifier |

## Compatibility

- Windows 64-bit and 32-bit
- Any mouse exposing standard XButton1/XButton2 events
- No manufacturer-specific software required
